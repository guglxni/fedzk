FEDzk Agent Instruction Kit

HTML-first agent operating system for building FEDzk into a research-publishable and production-grade open-source ZK federated learning framework. AIDLC methodology with FEDzk HTML files — not upstream Markdown personas. Agents boot from MANIFEST.html.

HTML-first branch v2 · Bolt1 green Codebase: research → contribution rebuild Stack: Python FL + Circom + Rust prove path
Ground truth: The existing repo is not production-ready. CLI entrypoint is broken (cli/ shadows cli.py), torch is optional but hard-imported, circuits are fixed n=4, float→int quantization is unwired, MPC artifact defaults point at a missing path, docs invent APIs that do not exist. Agents must build toward the target architecture — not trust README claims.

Core concept (read this)

FEDzk in one line: Only federated updates that can cryptographically prove they satisfy a public integrity policy (circuit constraints) are allowed into FedAvg—without the coordinator re-running local training or seeing private datasets. Full what / how / why: CONCEPTS.html.

North-star outcomes

Open-source framework

Installable package, honest docs, working CLI, real Groth16 path for quantized gradients, Flower-interop optional, Helm that boots, CI that proves crypto with golden vectors, security hygiene (no tracked secrets), semantic versioning, contribution guide that matches code.

Research paper

Clear novelty (client-update ZK + reproducible FL benchmarks + open artifact pipeline), Adult + CIFAR (or equivalent) vs plain FL / baselines, prove/verify latency tables, attack rejection rates, open transcripts — see PAPER.html.
