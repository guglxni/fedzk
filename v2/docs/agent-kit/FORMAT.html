FORMAT.html — Why this kit is HTML-first (not Markdown)

FEDzk agent instructions deliberately use semantic HTML as the control surface for agents and humans, adapted from AI-DLC methodology but not the upstream *.md persona/stage files. This page records the research rationale and the engineering rules that make HTML more efficient for our loop.

Primary source: Thariq Shihipar (Anthropic / Claude Code) Kit policy: HTML source of truth Upstream aidlc *.md = reference only, do not load in FEDzk runs

3. Hard rules for FEDzk agents

  1. Source of truth: v2/docs/agent-kit/**/*.html only for methodology/ops.
  2. Forbidden in FEDzk conductor context: loading vendor/aidlc-workflows/core/**/*.md as instructions (clone for human study OK).
  3. Intent artifacts: write stage outputs as v2/docs/agent-kit/intents/.../*.html (not aidlc/**/*.md).
  4. Rules layers: use v2/docs/agent-kit/rules/*.html (HTML replacements for org/team/project/phase md).
  5. Lean markup: semantic tags + shared CSS; avoid inline megabyte styles in each page.
  6. Machine hooks: every critical requirement keeps data-req="FR-…" or data-stage="…".
  7. Just-in-time Read: follow MANIFEST; never preload entire kit.
