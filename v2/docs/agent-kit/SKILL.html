Skill: fedzk-zk-golden

1. Prepare integer input.json matching circuit N
2. snarkjs wtns calculate circuit.wasm input.json witness.wtns
3. snarkjs groth16 prove circuit.zkey witness.wtns proof.json public.json
4. snarkjs groth16 verify verification_key.json public.json proof.json
5. Store under tests/goldens/<circuit>/ with SHA256SUMS
6. CI must reproduce verify=OK

Skill: fedzk-wire-quantize

Before any prove call:
  from fedzk.zk.input_normalization import GradientQuantizer
  q = GradientQuantizer(scale_factor=2**scale_bits)
  ints = q.quantize_gradient_dict(grads)
ZKProver must accept ints / quantized path only for snarkjs.
