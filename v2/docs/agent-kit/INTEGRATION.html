INTEGRATION — Wiring Upstream into FEDzk

Step-by-step integration instructions for toolchain, FL frameworks, Rust engine, and CI. Follow after cloning via REPOS.html.

Integration = making concepts executable: Circom compiles policy L; snarkjs/Rust prove the statement; Flower optionally orchestrates clients; coordinator enforces verify-before-FedAvg. Never integrate a path that bypasses verification. Round loop

1. Circom + snarkjs (developer machine)

# Node + Rust required for circom install paths — see iden3/circom README
npm install -g snarkjs
# or use npx snarkjs

# Build circom from vendor or releases
gh repo clone iden3/circom vendor/circom
# follow upstream build; ensure `circom` on PATH

./scripts/setup_zk.sh   # project script — fix paths if broken
fedzk doctor            # target command: checks circom, snarkjs, artifact hashes

Compile a circuit (normative)

cd src/fedzk/zk/circuits
circom model_update_secure.circom --r1cs --wasm --sym -o ../build
# Powers of Tau + groth16 setup (dev):
snarkjs groth16 setup model_update_secure.r1cs potXX_final.ptau circuit_0000.zkey
snarkjs zkey contribute circuit_0000.zkey circuit_final.zkey --name="dev"
snarkjs zkey export verificationkey circuit_final.zkey verification_key.json
# Record sha256 in artifacts/manifest.json

5. Rust fedzk-zk crate

mkdir -p crates/fedzk-zk
cd crates/fedzk-zk
cargo init --lib
# Cargo.toml deps (crates.io):
# ark-groth16, ark-bn254, ark-circom (or circom-compat), serde, serde_json, axum, tokio, tracing

Sidecar endpoints

  • GET /healthz
  • POST /v1/prove body: circuit_id, input JSON
  • POST /v1/verify body: vk_id, proof, public

Python façade

class RustEngine:
    def prove(self, circuit_id, inputs):
        return httpx.post(f"{URL}/v1/prove", json=...).json()
# ZKProver(engine="rust") uses RustEngine; engine="snarkjs" uses subprocess

Cross-verify CI job

snarkjs groth16 verify vk public proof_snarkjs.json
curl -s localhost:8088/v1/verify -d @golden.json
# assert both OK; also verify snarkjs proof with Rust and vice versa
