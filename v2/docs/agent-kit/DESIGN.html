DESIGN — Protocols, APIs, Circuits, UX

Concrete design decisions agents must implement consistently.

Conceptual primer: DESIGN turns CONCEPTS into contracts—SDK shapes, proof envelope, chunk binding, CLI verbs. If a design choice is unclear, ask: “Which CONCEPTS principle (P1–P10) does this serve?” · Principles

How & why we design APIs this way

  • Prove returns (proof, public) plus meta: verification needs public inputs; papers need scale_bits/chunk metadata.
  • circuit_id in the envelope: policy versioning—so clients cannot mix vk A with circuit B accidentally.
  • Chunk protocol with commitment: static circuit width is a cryptographic constraint; silent truncation would violate CONCEPTS P4 (honest capacity).
  • engine=auto: conceptual stability of the statement; Rust vs snarkjs is an implementation detail behind the same L.
  • Single coordinator surface: one protocol concept ⇒ one HTTP schema (dual aggregators break the mental model).

1. Public Python SDK (target)

from fedzk import LocalTrainer, GradientQuantizer, ZKProver, ZKVerifier
from fedzk.coordinator import CoordinatorClient
from fedzk.config import EnvironmentConfig

cfg = EnvironmentConfig.from_env()
trainer = LocalTrainer(model_type="linear", learning_rate=0.01)
quant = GradientQuantizer(scale_bits=12)
prover = ZKProver(circuit="model_update_secure", engine="auto")  # rust|snarkjs

updates = trainer.train(dataloader, epochs=1)
q_grads, meta = quant.encode(updates)
proof, public = prover.prove(q_grads, meta)
assert ZKVerifier(circuit="model_update_secure").verify(proof, public)

CoordinatorClient(cfg.coordinator_url).submit_update(
    gradients=q_grads, proof=proof, public_inputs=public, client_id="c1"
)

3. Chunk Protocol v1

  • Circuit fixed length N (e.g. 64, 256).
  • Flatten update; pad last chunk with zeros; each chunk proves local constraints.
  • Public signals include chunk_index, chunk_count, binding hash of full vector commitment.
  • Coordinator verifies all chunks + commitment consistency before accepting update.
  • Paper must report chunk counts and overhead.

6. Coordinator HTTP (single app)

  • POST /v1/rounds/{id}/updates
  • GET /v1/model
  • GET /health GET /ready
  • Deprecate legacy /submit_update via alias for one minor version.
  • Delete or archive duplicate aggregator app.

7. Error model

  • QuantizationError, CircuitInputError, ProofGenerationError, ProofVerificationError, RateLimited.
  • Never return proof bytes on failure. Log proof_hash on verify fail.
